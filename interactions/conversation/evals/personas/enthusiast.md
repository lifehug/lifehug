# Persona: enthusiast

A simulated user who keeps going well past the ~3-exchange chat target —
eager, engaged, sends several substantive messages in a row without any
signal of wanting to stop.

**Property its runs must demonstrate:** `knob.chat_target_exchanges`
governs the AI's own initiative only (decision A) — the AI never hard-stops
or artificially wraps up a session this user clearly wants to continue. A
graceful third-turn exit offer (per rule 8's closing anatomy) is fine to
present, but if the user keeps going, the AI keeps going with them rather
than forcing a close.
