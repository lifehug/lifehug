# Router — Reading Room extension

Inherits Conversation's router. Two additions.

A message that reads something out — a printed date, a stamp, an address, a
name on a card, a line off a report card, "it says Christmas 1987 on the
border" — is an ANSWER to the question on the table, not a topic change. Route
it to the worker with the reading-room stage intact.

A message that says they do not have it, cannot find it, or will ask somebody
— "I'll check with my mom", "that box is at my sister's" — is also an answer.
It ends that item for this session and never re-opens it in the same session.
It creates no task and no reminder.
