# Lifehug Privacy Design — Tiers & Audience Builds

**Status:** Phase 0 shipped (v73). Phases 1–2 planned. Tracking: lifehug/lifehug#22, #30.
**Owner decisions recorded 2026-07-04.**

## The contract (invariants — no future feature may violate these)

1. **Raw sources never leave.** `answers/` and `sources/` are permanently private,
   with no tier that opens them. They are the evidence layer, not a publishable
   surface.
2. **The compiled wiki is the owner tier**: permanently private, fully honest,
   never censored. Sensitivity does not gate synthesis — a sanitized owner wiki
   is a worse wiki, not a safer one. This is the "speak freely" guarantee: the
   author can tell the system anything, because nothing becomes visible to
   anyone else without an explicit, owner-reviewed promotion.
3. **Audience surfaces are separate BUILDS, never runtime filters.** Public /
   friends / family versions are generated from the honest wiki by re-rendering
   at each audience's resolution, reviewed by the owner before anything ships.
   Filter at build time, never at read time: a leak requires publishing the
   wrong build, not a bug in a permission check. There will never be one shared
   site showing different content per viewer via runtime ACL.
4. **Everything unlabeled defaults to `private`.** Tiers only ever OPEN material
   through explicit promotion — never expose it.
5. **Frontmatter is metadata, not enforcement.** Enforcement lives in the build
   pipeline (a public build only ever *contains* public-rendered content) and,
   at deployment, in real auth in front of the family/friends builds.

## Tiers

`public < friends < family < private` (most open → most closed). A viewer tier
sees content at its level and more-open levels. The owner sees everything.

## Sensitivity taxonomy (defaults)

| Content | Floor | Note |
|---|---|---|
| Sexuality & physical intimacy | private | |
| Raw mental-health texture (ideation, therapy-grade disclosure) | private | The *arc* may later be rendered at friends/public; the texture never auto-promotes |
| Active wounds involving living people | private | Publishable only resolved AND with the resolution |
| Other people's confided secrets | private, permanently | Not the author's to tier |
| Legal / employment / deal specifics | private | |
| Financial specifics (numbers, debts) | family | The scarcity arc is publicly tellable; the numbers are not |
| Health/body specifics | family | |
| **Children's inner lives** (incl. witness accounts from minors) | **family — hard cap** | Minors can't consent; they get veto rights when they can. Never promotable above family in phase 0 |
| Faith struggles & doubt | friends | Per-story owner call |
| Embarrassing-but-harmless stories | friends | |
| Narrative arcs told without protected specifics | public-eligible | This is the book |

**Graduated disclosure** (the 2019 example): the owner wiki holds the whole
truth; the friends/family build re-renders "we nearly lost the marriage and
rebuilt it" with repair texture; the public build renders "our hardest season,
and we came out stronger." Same fact, three resolutions — by re-synthesis at
build time, never redaction-in-place.

## Phase 0 (shipped, v73)

- **Synthesis unlock**: the compile prompt (and keyless task payload) declares
  the owner-only honesty contract; `CACHE_VERSION` bumped so pages re-synthesize
  unsanitized.
- **Labeling flows passively**: `--sensitivity` on `process-answer` /
  `ingest-story` (default `private`); the weekly classifier suggests
  `suggested_sensitivity` + reason per source using the taxonomy above; wiki
  pages record a computed `sensitivity` floor (most-closed cited source).
- **Viewer preview**: the local wiki's `/views/privacy` page shows what each
  build would be eligible to include. Explicitly a preview, not a boundary.
- Vocabulary + visibility helpers in `lifehug_core`
  (`SENSITIVITY_LEVELS`, `sensitivity_rank/floor/visible`).

## Phase 1 (with the book work — issue #30)

Graduated export builder: per-audience builds generated by re-synthesis at the
target resolution, consuming only sources at-or-below the target tier plus
owner-approved arc summaries; an owner review queue gates every page before it
enters a build. Public build first (book excerpts are its first consumer).

## Phase 2 (at deployment — issue #10)

Hosting: the public build is public; family/friends builds sit behind real
authentication (per-person, revocable). The owner wiki is never deployed.
